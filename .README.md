# Portafolio personal de César Tomás

Proyecto académico desarrollado con Django, HTML, CSS y JavaScript.

Presenta mi formación como estudiante del Técnico Universitario
en Informática, mis habilidades y tres proyectos de aprendizaje.

## Páginas

- Inicio.
- Sobre mí.
- Habilidades.
- Proyectos.
- Contacto.
- Error 404 personalizado.

## Funcionalidades

- Diseño adaptable a computadora y celular.
- Menú desplegable en móvil.
- Filtro de proyectos por categoría sin recargar la página.
- Validación del formulario de contacto.
- Enlaces a los proyectos publicados y a sus repositorios.

El formulario es una demostración: no envía ni guarda mensajes.
El contenido del portafolio no utiliza modelos ni base de datos.

## Ejecutar en Windows

Se necesita Python instalado.

1. Descarga y descomprime el repositorio.
2. Abre una terminal de tipo Command Prompt en la carpeta
   que contiene manage.py.
3. Ejecuta:

```bat
py -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt
python manage.py runserver
```

4. Abre en el navegador:

http://127.0.0.1:8000/

Cada vez que abras una terminal nueva, activa el entorno virtual
antes de iniciar el servidor.

## Probar el sitio

- Visita las cinco páginas desde el menú.
- En Proyectos, selecciona cada categoría y luego Todos.
- En Contacto, prueba campos vacíos, correo incorrecto y datos válidos.
- En una vista móvil, abre y cierra el menú.
- Comprueba los botones Ver proyecto y Ver código.

## Página 404

Durante el desarrollo, su diseño se puede revisar en:

http://127.0.0.1:8000/404/

El controlador de direcciones inexistentes está configurado.
Django lo utiliza cuando DEBUG es False; con DEBUG en True
muestra su página técnica para esas direcciones.

## Configuración

La configuración incluida es para desarrollo local.
Para un despliegue público se debe configurar una clave privada
mediante DJANGO_SECRET_KEY y ajustar la configuración del servidor.
